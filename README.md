# Blog Preview Card

A static blog preview card created with HTML and CSS as a Frontend Mentor challenge.

## Preview

The page displays a blog card with a category label, publication date, title, description, author details, and images.

## Built with

- HTML
- CSS
- Google Fonts (Figtree)

## Project structure

```text
. 
├── index.html
├── css/
│   └── style.css
└── images/
    ├── Blog Image.svg
    ├── Pointer.png
    ├── Pointer.svg
    └── userpic.png
```

## Run locally

Open `index.html` in a web browser.
